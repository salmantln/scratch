## Interface changes

| Before | After |
| --- | --- |
| Blank-note-first workspace | Meetings are the default entry point; notes are one meeting tab. |
| Demo meetings seeded silently | First launch asks for a project; examples are opt-in and badged Example. |
| Hard-coded projects | Projects are created in-app and map to archive folders. |
| Library with tagline, motif, filters and footers | Plain title, time-grouped rows, status only when it needs attention. |
| Capture as the way to create a meeting | New meeting (title optional) is separate from Start capture. |
| Simulated waveform, pause and "Preparing your notes…" | Honest prototype capture: state, timer, Stop, "Capture ended. No audio was recorded." |
| Canned summary on new meetings | Empty states: "No summary yet.", "Transcript unavailable." |
| Search as a filtered library | Dedicated ⌘K search with context snippets that opens the matching tab. |
| Privacy mixing real and planned toggles | *Active now* facts plus one enforced switch; a separate *Planned* group. |
| Raw archive path as headline | Open archive / Reload; path under Advanced. |
| One generic error banner | Distinct states for unreadable archive, failed save, recovered draft, outside changes, interrupted meeting. |
| Scratch identity and icons | QuietNote identity; one consistent outline icon set. |
| Upstream update/release identity | Automatic upstream update checks disabled; release workflow is a manual QuietNote draft. |
