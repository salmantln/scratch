## Interface changes

| Before | After |
| --- | --- |
| Blank-note-first workspace | Meeting library and summary are the default entry points. |
| Scratch identity and icons | QuietNote identity and concentric pulse across favicon, desktop icons and capture. |
| Generic notes/folders navigation | Meetings, recent records, projects/clients, search, settings and persistent capture. |
| Editor as the entire product | Original editor inside Manual notes; separate transcript and structured review views. |
| General note presentation | Compact meeting rows with project/date/duration/status and Markdown tasks with owners. |
| Generic monochrome surfaces | Warm ivory, navy text, cobalt actions and subtle mint statuses using landing-page colors. |
| No capture workflow | Compact, explicitly simulated capture with pause/stop and user-control properties. |
| Generic settings as primary configuration | Privacy-focused settings distinguish working controls from planned preferences. |
| Editor/diagram code loaded on startup | Editor loads on demand; large retained diagram engine loads only for Mermaid blocks. |
| No recovery drafts in the meeting adapter | Immediate draft backups, retry, serialized writes and close handling. |
| Spacious initial detail header | Compact detail header makes more action items visible at desktop window heights. |
| Unspecified responsive meeting layouts | Dense table adapts through 600/800/1080/1440px; secondary columns hide at smaller widths. |
| Upstream update/release identity | Automatic upstream update checks disabled; release workflow is a manual QuietNote draft. |
